# Academic Universe - AI Context Document

This document provides a structured overview of the "Academic Universe" project to help an AI assistant quickly understand the architecture, tech stacks, file structure, and core features.

## 1. Project Overview
Academic Universe is a multi-tenant SaaS educational platform that transforms traditional evaluation by incorporating holistic student development tracking. It measures comprehensive growth through IQ/EQ assessments, mental wellness tracking, and verified credentials, moving beyond conventional marks and attendance. It supports completely automated role assignment based on institutional email domains.

## 2. Technical Stack
**Frontend Ecosystem:**
- Framework: Next.js 16.1.6 (App Router)
- UI Library: React 19.2.3, React DOM 19.2.3
- Language: TypeScript 5.7.3
- Styling & Components: Tailwind CSS, Radix UI Primitives, class-variance-authority, clsx, tailwind-merge, lucide-react.
- Other libraries: embla-carousel-react, react-hook-form, zod, recharts.

**Backend Ecosystem:**
- Framework: Node.js with Express.js 4.18.0
- Database: MongoDB 7.0.0 with Mongoose ODM
- Authentication: Firebase Admin SDK 12.9.0 + Custom JWT tokens with bcryptjs for password hashing.
- Document Generation (PDF/Word): docx, jspdf, html2pdf.js, mammoth.

## 3. Core Features
1. Automatic Role Detection: 
   - `@ug.sharda.ac.in` / `@pg.sharda.ac.in` -> STUDENT
   - `@fa.sharda.ac.in` -> FACULTY
   - Powered by Server-side Firebase token verification.
2. Verified Record System: Centralized profiles for reliable achievements, eliminating scattered Google Forms.
3. Holistic Growth Engine: Weekly IQ/EQ assessments, AI growth degradation alerts, stress and burnout detection.
4. AI Support Systems: Emotional Intelligence Chatbot, Research Assistant, Personalized Recommendations.
5. Gamification & Competitive Arena: Leaderboards, integrations with coding platforms (GitHub, LeetCode, Codeforces), and bug bounties.
6. Multi-Tenancy: Supports multiple organizations with complete data isolation and RBAC (SUPER_ADMIN, ADMIN, FACULTY, STUDENT).

## 4. Architecture & File Structure
The repository follows a decoupled architecture within a single repository structural setup:

- `/app/` - Next.js 13+ App Router components, screens, and API routes.
- `/backend/` - Complete Express.js server, containing MongoDB schemas, auth controllers, and middleware.
- `/components/` - Global and shared React UI components (likely shadcn/ui components).
- `/lib/` & `/utils/` - Shared helper modules, constants, and typed configurations.
- `/hooks/` - Custom React hooks for state and data fetching.
- `/styles/` - Global CSS files and Tailwind directives.
- `/public/` - Static assets like images and metadata.
- `/scripts/` - Custom build and utility scripts.
- `/firebase.json` & `/firestore.rules` - Firebase configuration and security rules.
- `/package.json` - Workspace definition and dependencies (using scripts like "dev", "build", "start").

## 5. Development & Deployment
- Environments: Frontend defaults to `http://localhost:3000`, Backend defaults to `http://localhost:5000`.
- Scripts: `start-dev.bat` and `start-dev.ps1` for local setup orchestration. Database seeding available via `cd backend && npm run seed`.
- Data flows via REST APIs (`/api/marks`, `/api/auth`, etc.) securely authenticated with JWT Bearer tokens containing embedded RBAC permissions.
