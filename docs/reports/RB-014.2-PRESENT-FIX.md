# RB-014.2: Attendance Present Extraction Fix Report

## Issue
Live verification showed dashboard attendance summary returning:
- `total = 7`
- `present = N/A`
- `absent = 3`
- `percentage = 0`

Only the `Present` field failed to extract; `Total` and `Absent` worked correctly.

## Root Cause
In `ezone.scraper.ts`, the widget-scoped attendance extractor compares trimmed label text against hardcoded strings:

```typescript
const label = labelEl?.textContent?.trim() || '';
// ...
else if (label === 'Present ') result.present = value;
```

Because `.trim()` removes trailing whitespace, the label `"Present "` from the DOM becomes `"Present"`, but the comparison checks for `'Present '` (with trailing space). The condition never matches, so `result.present` remains unset and falls back to `'N/A'`.

## Fix Applied
**File:** `backend/src/modules/ezone/scrapers/ezone.scraper.ts`

**Change 1 — Selector correction (line 182):**
```typescript
// Before
else if (label === 'Present ') result.present = value;

// After
else if (label === 'Present') result.present = value;
```

**Change 2 — Fallback derivation (lines 186-192):**
```typescript
if (!result.present && result.total && result.absent) {
    const totalNum = parseInt(result.total) || 0;
    const absentNum = parseInt(result.absent) || 0;
    if (totalNum >= absentNum) {
        result.present = String(totalNum - absentNum);
    }
}
```

If the `Present` label still cannot be located for any reason (e.g., markup variation), the extractor now derives `present` arithmetically as `total - absent`. The existing `sanitizedData` computation already calculates `attendancePercentage` as `Math.round((present / total) * 100)` from these counts.
