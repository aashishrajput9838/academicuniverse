## 2. Exact Changes

### Before (lines 150-167)

```ts
if (!isAdminOrFaculty) {
  // Find the user's section to match section-level templates
  // We don't need to look up Section manually if frontend doesn't provide it, 
  // because we solely rely on type 'global' or matching specific frontend inputs.
  const targets: string[] = [];
  if (req.query.target && typeof req.query.target === 'string') {
    targets.push(req.query.target); // Frontend passes specific department or section name like 'CSE' or 'CSE-A'
  }

  // Base query: templates for this org that are 'global', OR matching specific target provided by frontend
  query = {
    organizationId,
    $or: [
      { type: 'global' },
      { target: { $in: targets } }
    ]
  };
}
```

### After (lines 150-185)

```ts
if (!isAdminOrFaculty) {
  const targets: string[] = [];
  if (req.query.target && typeof req.query.target === 'string') {
    targets.push(req.query.target.trim());
  }

  if (targets.length === 0) {
    try {
      const { default: EzoneAcademicProfile } = await import('../models/EzoneAcademicProfile');
      const profile = await EzoneAcademicProfile.findOne({
        userId: req.user.userId,
        organizationId,
      });
      if (profile?.department) {
        targets.push(profile.department.trim());
      } else {
        logger.warn(`No department found in EzoneAcademicProfile for user ${req.user.userId}; falling back to global templates only`);
      }
    } catch (profileError) {
      logger.warn(`Failed to load EzoneAcademicProfile for user ${req.user.userId}:`, profileError);
    }
  }

  const targetPatterns = targets.map(t => {
    const escaped = t.replace(/[.*+?^${}()|[\]\\]/g, '\\$&');
    return new RegExp(`^${escaped}$`, 'i');
  });

  query = {
    organizationId,
    $or: [
      { type: 'global' },
      { target: { $in: targetPatterns } }
    ]
  };
}
```

## 3. What Changed and Why

| Change | Reason |
|--------|--------|
| Removed stale comments about section matching | Cleanup; section matching not implemented yet |
| `targets.push(req.query.target.trim())` | Normalize whitespace from frontend-provided target |
| Added `EzoneAcademicProfile` lookup when `targets` is empty | Auto-resolve student department as fallback |
| `profile?.department` check with trim | Safely read department; normalize whitespace |
| `logger.warn` when no profile/department found | Observability; debug why student sees only globals |
| `try/catch` around profile lookup | Graceful degradation; never throw on missing profile |
| Regex patterns with `i` flag | Case-insensitive matching: "CSE", "cse", " CS " all resolve |
| Regex escape for special chars | Prevent regex injection from unexpected target values |
| `$in: targetPatterns` instead of `$in: targets` | Enables case-insensitive comparison without schema changes |

## 4. Behavioral Changes

|----------|--------|-------|

| Template target = "CSE", student dept = "cse" | Not matched | Matched (case-insensitive) |

| `EzoneAcademicProfile.department` is null | Returns global only | Returns global only + warning log |
| Faculty/admin requests templates | Unchanged | Unchanged |
| Frontend passes `?target=CSE` | Exact match only | Case-insensitive match |
