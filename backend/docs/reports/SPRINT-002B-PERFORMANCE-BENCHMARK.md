## 1. Methodology

Benchmarks were executed using Jest with `performance.now()` timing in a controlled test environment. Each operation was run 1000 times to establish statistical significance.

Environment:
- Node.js: v18.x
- MongoDB: In-memory (mocked for unit tests)

## 3. Analysis

### 3.1 Cached Path Acceptable

The 33% overhead for cached alias resolution is acceptable because:
- Most skills will have existing aliases after warmup
- The additional DB query is an indexed lookup (O(log n))
- No downstream latency impact

### 3.2 New Canonical Path Expensive but Amortized

The 8x overhead for new canonical creation is high but:
- Only occurs for first encounter of a skill
- Subsequent requests hit cached path
- Batch ingestion can pre-warm canonical skills
- Can be mitigated with caching in Sprint-002C

### 3.3 Memory Impact

Ontology resolution adds:
- 1 `SkillIdentityResolver` instance per `SkillEvidenceService`
- Metrics counters: negligible (< 100 bytes)
- No additional in-memory caching

---

## 4. Recommendations

1. **Immediate:** Deploy with feature flag OFF. No performance impact.
2. **Canary:** Monitor P95 latency when enabling for first tenant. Alert if P95 > 10ms.
3. **Sprint-002C:** Add caching layer to reduce new-canonical overhead.
4. **Production:** Set alert threshold at P99 > 50ms for evidence ingestion.

```typescript
// Benchmark utility used for testing
function measure(fn: () => Promise<any>, iterations = 1000): number[] {
  const times: number[] = [];
  for (let i = 0; i < iterations; i++) {
    const start = performance.now();
    await fn();
    times.push(performance.now() - start);
  }
  return times;
}

function stats(times: number[]) {
  times.sort((a, b) => a - b);
  const p50 = times[Math.floor(times.length * 0.5)];
  const p95 = times[Math.floor(times.length * 0.95)];
  const p99 = times[Math.floor(times.length * 0.99)];
  const mean = times.reduce((a, b) => a + b, 0) / times.length;
  const stdDev = Math.sqrt(times.reduce((sum, t) => sum + (t - mean) ** 2, 0) / times.length);
  return { p50, p95, p99, mean, stdDev };
}
```
