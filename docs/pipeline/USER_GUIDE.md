# USER GUIDE: AUTOMATED PUBLICATION PIPELINE

---

## 1. Quick Start

Run the automated pipeline command:

```bash
python -m paper_pipeline.main
```

## 2. Output Artifacts

The pipeline automatically outputs:
- `docs/paper/Paper_V3_IEEE.docx` (Publication-ready Word Document)
- `docs/paper/Paper_V3_IEEE.pdf` (Publication-ready PDF Document)
- `docs/reports/*.md` (All 8 Automated Reports)
