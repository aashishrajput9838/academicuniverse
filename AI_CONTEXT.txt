# Academic Universe - Master AI Context (Token-Optimized)

## 1. Project Essence
Multi-tenant SaaS for holistic student development tracking. Moves beyond marks to IQ/EQ, wellness, and verified credentials. Automated RBAC via email domains.

## 2. Core Technical Stack
- **Frontend**: Next.js 16 (App Router, Turbopack), React 19, Tailwind CSS 4, Radix UI, Lucide.
- **Backend**: Node.js, Express 5, TypeScript.
- **Databases**: 
  - **MongoDB**: Primary store for users, roles, organizations, marks, and resumes.
  - **Firebase/Firestore**: Client-side event streaming, detected events, and real-time data.
- **Auth**: Hybrid (Firebase Auth for login + Custom JWT with embedded RBAC permissions).
- **AI**: Google Gemini (gemini-2.5-flash) for EI Chatbot and Research Wing.
- **External**: GitHub API (Analytics), Gmail API (Event Detection via sync).

## 3. Architecture & Patterns
- **Monorepo-style**: Root contains Next.js app; `/backend` contains Express server.
- **Modular Backend**: New features follow `/backend/src/modules/` pattern (e.g., Research).
- **Service Layer**: Business logic isolated in `/backend/src/services/` (GmailSync, Analytics, AI, Overlap).
- **Isolation**: Multi-tenancy enforced via `organizationId` on all schemas and queries.

## 4. Key Services & Features
- **Automatic RBAC**: Domain-based (@ug.sharda.ac.in -> STUDENT, @fa.sharda.ac.in -> FACULTY).
- **Overlap Engine**: Finds common free slots across sections (max 5) for event scheduling.
- **Gmail Event Detector**: Syncs emails, filters spam, and extracts hackathons/exams into Firestore.
- **GitHub Analytics**: Periodically (6h) syncs repo stats, languages, and commit trends.
- **EI Chatbot**: Empathetic AI assistant cross-referencing student's timetable and mood.
- **Research Wing**: Modular system for topic generation, content writing, and paper finalization.

## 5. Directory Map
- `/app/dashboard/[role]/`: Role-specific frontend routes.
- `/backend/src/controllers/`: API entry points.
- `/backend/src/models/`: Mongoose schemas (User, Timetable, Section, etc.).
- `/backend/src/services/`: Core logic (AI, Sync, Analytics).
- `/components/`: UI library (Chat, Mess, Research, SoftSkills, UI-shared).
- `/firestore.rules`: Security for real-time collections.
- `/scripts/`: Build wrappers and DB seeders.

## 6. Development Rules
- **Backend Port**: 5000 | **Frontend Port**: 3000.
- **Auth**: Always use `authenticateFirebaseUser` middleware for protected routes.
- **Environment**: Strict CSP and Glassmorphism UI style.
- **Deployment**: Vercel (Frontend), Render (Backend), Firebase (Rules/Indexes).
